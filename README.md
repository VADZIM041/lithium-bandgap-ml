# Lithium Band Gap ML Predictor

Это веб-приложение на базе Streamlit и машинного обучения, которое предсказывает ширину запрещенной зоны (band gap) для материалов, содержащих литий.

## 🛠 Технологии
* Python
* Pandas, Scikit-learn (Random Forest)
* Pymatgen (для парсинга химических формул)
* Streamlit (веб-интерфейс)
* Materials Project API (источник данных)

## 🚀 Как запустить локально
1. Установите зависимости: `pip install -r requirements.txt`
2. Запустите приложение: `streamlit run app.py`
